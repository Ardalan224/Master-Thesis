# Master-Thesis
This public GitHub repository contains the Python code used for the experiments conducted in my Master's thesis, titled: "Optimal Dataset Size for Recommender Systems: Evaluating Algorithms' Performance via Downsampling."

The programs uploaded here represent the general structure of the code used in the experiments. In some cases, adjustments may have been made to adapt the code for specific scenarios or experimental requirements. Additionally, the exact set of random seeds and hyperparameters used in the experiments may differ from those specified in the uploaded programs.
